# Adam Chronister Personal Branding Website

A modern, responsive personal branding website inspired by Adam Chronister's professional brand. Built with React, TypeScript, Vite, and Tailwind CSS, the project emphasizes performance, clean design, and an engaging user experience.

## 🚀 Overview

This project showcases a premium personal branding website designed to highlight professional expertise, services, publications, achievements, and contact information through a modern and visually appealing interface.

## ✨ Features

- Responsive design for all screen sizes
- Modern hero section
- Professional branding and typography
- Smooth navigation experience
- Services showcase
- Author and speaker highlights
- Contact section
- Reusable React components
- Fast performance with Vite
- Type-safe development using TypeScript

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- HTML5
- CSS3

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/luffy6206/adam-chronister-personal-branding-site.git
```

Navigate to the project directory:

```bash
cd adam-chronister-personal-branding-site
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🏗️ Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
